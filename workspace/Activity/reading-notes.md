# Reading the activity view

The cards in `Activity/index.json` are saved content. Their labels describe the notes; they are not a live task runner.

Use this folder for receipts, release notes, research summaries, or outputs written by a process you control. A collection card can link to any workspace-relative file or folder.

For example, a script can write a new Markdown summary here and add a card to `index.json`. The app will pick up both changes on its next refresh.
