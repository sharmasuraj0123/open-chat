# A small acceptance checklist

- Open a top-level folder from the dock.
- Navigate into a nested folder and back again.
- Read a Markdown document.
- Inspect an ordinary JSON file and its raw source.
- Open the CSV inventory.
- Change a message in a conversation file and see it refresh.
- Add or rename a top-level folder and see navigation refresh.
- Remove a selected file and check that the interface handles its absence.

This is a saved checklist for manual verification, not a test-results report.
